# Rhyo · Bstation Creator (v2.0)

Website statis tanpa build. Tema HUD game biru dan maskot TV dari proyek Bstation Creator Quest.

- Edit data ambasador (nama, kode ref, WA, IG) di `config.js`.
- `js/play.js`: item halaman bisa diseret, dilempar, dihancurkan (state machine, tanpa kloning elemen).
- `js/mascot.js`: maskot fisika, bisa dibanting, dilempar, dipukul, dan memperbaiki item seketika.
- Ganti `DOMAIN-KAMU` di `robots.txt` dan `sitemap.xml` setelah domain siap.
